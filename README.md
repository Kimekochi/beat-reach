# Beat Reach

Ритм-игра в духе osu! для вебки: круги появляются в такт музыке, а бьёшь их руками перед камерой.

**Играть:** https://kimekochi.github.io/beat-reach/

## Как играть

1. Загрузи свою песню (mp3, ogg, wav, m4a) или включи демо-бит.
2. Проверь BPM и офсет кнопкой «Проверить с метрономом».
3. Нажми «Включить камеру» и разреши доступ.
4. Нажми «Откалибровать задержку по метроному» и 16 раз выстрели в щелчок. Игра сама поставит задержку камеры.
5. Сложи руку пистолетом: указательный палец вперёд, большой вверх. Опусти большой палец, это выстрел.

Розовые круги для левой руки, голубые для правой. Слайдеры ведёшь прицелом за шариком. `Esc` ставит на паузу. Без камеры можно играть мышкой.

## Как это устроено

- Один файл `index.html`, без сборки и сервера.
- Трекинг рук: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker), работает прямо в браузере, видео никуда не отправляется.
- BPM и первая доля находятся автоматически по огибающей громкости трека.
- Карта собирается из паттернов (многоугольники, дуги, зигзаги, прыжки, пары для двух рук) с учётом того, куда руки могут дотянуться.

Лучше всего работает в Chrome или Edge.
